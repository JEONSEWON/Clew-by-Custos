# Data provenance

Files in this directory derived from the SWE-chat dataset
(`swechat_waste_cases.csv`, `swechat_waste_cases_v2.csv`,
`swechat_waste_sample20.json`) are **not** covered by this repository's
MIT license. They remain under the Open Data Commons Attribution License.

Contains information from [SWE-chat](https://huggingface.co/datasets/SALT-NLP/SWE-chat)
which is made available under the
[ODC Attribution License](https://opendatacommons.org/licenses/by/1-0/).

Source: SALT-NLP/SWE-chat — arXiv:2604.20779
These files are analysis outputs (derived rows), not redistributions of the
full dataset. They contain file paths and tool arguments from real developer
sessions as published in the source dataset.
